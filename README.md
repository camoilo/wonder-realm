# 多模式对话机器人

一个完全在本机运行的对话应用：模型走本地 Ollama，数据存本地 SQLite，不依赖任何云端 API。支持三种对话模式，带角色卡、可随时调整的生成要求、跨会话的长期记忆，以及完整的消息编辑与重生成能力。

## 三种模式

| 模式 | 生成内容 | 绑定角色 | 长期记忆归属 |
|---|---|---|---|
| **角色对话** | 只有角色说出的话 | 是，会话创建时选定 | 按角色，该角色所有会话共享 |
| **角色情境** | 角色话语 + 情境说明 | 是，与角色对话共用同一套角色 | 与角色对话共用同一份角色记忆 |
| **自由情境** | 自由生成的对话与情境 | 否 | 按会话独立保存 |

角色对话与角色情境共享角色卡和长期记忆——在任一模式下聊过的关键信息，切到另一个模式也记得。角色之间、会话之间的记忆互不可见。

但两个角色模式的**会话列表相互隔离**：角色对话里只列出角色对话创建的会话，角色情境里只列出角色情境创建的会话，互相看不到、也打不开；切换模式 Tab 会回到你上次在该模式看的那条会话。三种模式里，只有自由情境的会话与角色无关。

## 主要功能

**角色卡**：外观、性格、语言风格、背景故事，随时可改，下一次生成即生效。

**生成要求**：挂在会话上而不是角色上，因此同一个角色可以有"简短闲聊"和"详细演绎"两种用法互不干扰。每个模式一套字段，其中**导演指令**单独成段注入提示词——它只影响情境与剧情走向，不会作为消息进入对话历史，角色也不会"说出"收到了指令。自由情境模式另有**情境/台词配比**（只有情境 / 情境为主 / 均衡 / 台词为主）：可以整段只写情境、完全不出现台词，也可以让情境远多于台词，不必两者交替出现。

**长期记忆**：会话内消息超过阈值（默认 6000 字符）后，后台自动把较早的消息压缩成一份结构化摘要，不需要用户操作。摘要会注入后续生成的提示词，可在右侧面板查看与手动修改。摘要长度、压缩阈值、批量条数都可配置。

**消息操作**：任意消息都可编辑（双击气泡或点"编辑"）与删除（单条或连着后面一起删）；生成消息可重新生成，以该消息之前的上下文为基准替换。生成过程中可以随时**停止**，已经流出的部分照常保留，不会白费。会话绑定的角色被删除后，该会话只可查看，重新生成按钮不再提供（即使通过接口发起也会被拒绝，且不会删掉已有消息）。

**会话标题自动命名**：创建会话时留空标题，说够内容后由模型异步总结一个标题；手动改过名的会话不会再被自动覆盖。

**模型随时切换**：顶栏下拉框只列本机已安装的模型，切换立即生效、重启不丢。思考型模型（qwen3 等）与普通模型都能直接换——推理过程由应用层剥离，只显示"思考中"占位，不会污染消息内容。

## 技术栈

| 层 | 选型 |
|---|---|
| 模型服务 | 本机 Ollama（默认 `http://localhost:11434`） |
| 后端 | Python 3.13 + FastAPI + SQLite（WAL 模式） |
| 依赖管理 | uv |
| 前端 | Vue 3（CDN 引入，无构建流程）+ 原生 CSS |
| 流式输出 | SSE（`fetch` + `ReadableStream` 手动解析） |

设计取舍与实现细节见 [DEVELOPMENT.md](./DEVELOPMENT.md)。

## 开始使用

### 1. 准备 Ollama

安装 [Ollama](https://ollama.com/download) 并拉取一个模型：

```powershell
ollama pull qwen2.5:3b
```

确认服务在跑（Ollama 安装后会自动常驻）：

```powershell
curl http://localhost:11434/api/tags
```

小模型响应快、占用低，适合先跑通；想要更好的角色扮演与格式遵循效果，可以换更大的模型（例如 `qwen3.5:4b`），在界面顶栏切换即可。

### 2. 安装 uv

```powershell
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

### 3. 安装依赖

在项目目录下执行（uv 会按 `.python-version` 自动准备 Python 3.13，无需手动装）：

```powershell
uv sync
```

### 4. 启动

```powershell
uv run run.py
```

也可以直接双击项目根目录的 `start.bat`（或指向它的桌面快捷方式）：省去开终端敲命令，启动后会自动用默认浏览器打开页面；服务已在运行时再双击一次不会重复启动，只会把页面重新打开。关掉那个命令行窗口即停止服务。

看到 `Uvicorn running on http://127.0.0.1:8000` 后，浏览器打开：

```
http://127.0.0.1:8000
```

### 5. 第一次使用

1. 在**角色对话**或**角色情境**模式下点"新建角色"，填写角色卡
2. 点"新建会话"（标题可留空，之后会自动命名），开始对话
3. 右侧面板里可以调生成要求、改角色卡、看记忆
4. 想写自由剧本就切到**自由情境**模式，直接新建会话即可

> 两个角色模式的会话是分开的：在角色对话里建的会话不会出现在角色情境的列表里，反之亦然。切模式 Tab 会回到你上次在该模式看的那条会话。

## 界面说明

三栏布局，左右两栏都可以收起，对话内容始终居中：

```
┌──────────┬─────────────────────────────┬──────────────┐
│ 模式Tab  │ [☰] 标题 [模式] [模型] [面板]  │              │
│──────────├─────────────────────────────┤  右侧面板     │
│ 列表区    │      消息流（居中留白）       │  · 生成要求   │
│ ·角色列表 │                             │  · 角色卡编辑 │
│ ·或会话   │                             │  · 记忆查看   │
│──────────├─────────────────────────────┤              │
│ [新建]    │  [输入框           ] [发送]  │              │
└──────────┴─────────────────────────────┴──────────────┘
```

- 消息悬停后出现操作条：复制 / 编辑 / 删除 / 重新生成；也可以直接双击气泡进入编辑。会话绑定的角色被删除后，该会话只可查看，"重新生成"按钮不再出现
- 生成中输入框右侧的按钮变为"停止"
- 左侧 `☰` 收起左栏，顶栏"面板"按钮收起右栏，收起后对话区自动重新居中
- 被压缩归档的消息默认折叠为"已归档 N 条"，点击可展开查看原文
- 切换模式 Tab 只换左侧列表与当前会话：两个角色模式的会话互不显示，各自记住上次打开的那条

## 配置

改 `config.yaml` 后重启生效：

```yaml
ollama:
  base_url: http://localhost:11434
  model: qwen2.5:3b              # 首次启动的默认模型；之后以界面选择为准
  options:
    temperature: 0.8
    num_ctx: 8192

memory:
  model: ""                       # 压缩用模型，留空 = 同对话模型
  compress_threshold_chars: 6000  # 未归档消息超过该字符数触发压缩
  archive_batch_size: 20          # 每次归档的消息条数
  max_memory_chars: 600           # 记忆摘要长度上限

chat:
  history_max_messages: 60        # 注入历史的最大条数（从最早开始截断）

naming:
  model: ""                       # 会话自动命名用模型，留空 = 同对话模型
  max_chars: 12                   # 自动标题字数上限
  min_user_chars: 8               # 用户累计发言少于该字数时先不命名

server:
  host: 127.0.0.1
  port: 8000

data_dir: ./data                  # 数据库目录
```

想快速验证记忆功能，可以把 `compress_threshold_chars` 临时改小（如 500），聊几轮就能看到归档折叠与记忆内容。

## 数据

所有数据都在 `data/chatbot.db` 这一个 SQLite 文件里（含角色、会话、消息、记忆、模型选择）。备份直接复制该文件；想彻底重置就删掉它，下次启动会自动重建空库。

数据库是单用户设计，没有鉴权，服务只监听 `127.0.0.1`，不要对外暴露。

## 常见问题

**顶栏提示"无法连接 Ollama"**
Ollama 没启动或端口不对。执行 `ollama list` 确认能正常返回，必要时手动启动 Ollama。

**顶栏提示"所选模型未安装"**
上一次选的模型被删了，或换机器后模型没同步。在顶栏下拉框里重新选一个已安装的模型即可。

**生成很慢或首字等很久**
取决于本机模型大小与硬件。换更小的模型（如 `qwen2.5:3b`）会明显变快；界面上会先显示"生成中"，思考型模型会先显示"思考中"，都属于正常等待。

**模型不按格式输出情境**
小模型偶发。程序不会因此丢内容——解析不出标记时会整体当作话语显示。可以在生成要求里把情境篇幅调小、或用更大的模型改善遵循度。

**自由情境总是又写情境又写台词**
在右侧面板把"情境/台词配比"调成"只有情境"或"情境为主"即可。这个字段默认是"均衡"，模型拿不到明确要求时容易两边都写一点。

**在角色对话里看不到我在角色情境建的会话**
这是有意的：两个角色模式的会话列表相互隔离。切到角色情境模式就能看到，两边各自记住上次打开的那条会话。角色卡与长期记忆仍然是共用的。

**删了角色，那个会话还能用吗**
只能查看历史：输入框会禁用，"重新生成"按钮也不再出现。即使直接调接口发起生成也会被拒绝，并且已有消息不会被删除。想继续用就重建一个角色、开新会话。

**记忆什么时候更新**
每次生成完成后后台检查，超过阈值才压缩，不阻塞对话。想立刻看到效果就把阈值改小；压缩结果可在右侧面板查看与手动修改。

**删了消息，记忆会跟着变吗**
不会。记忆是"曾经发生过的事"的沉淀，已归档的内容不随消息删改回滚。需要修正就手动编辑面板里的记忆。

**必须联网吗**
运行时不需要，模型和数据都在本地。只有首次加载页面会从 CDN 取 Vue，如果完全离线，把 `index.html` 里的 Vue script 换成本地文件即可。
