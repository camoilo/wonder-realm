# Wonder Realm（奇想界域）

一个完全跑在你电脑上的 AI 角色扮演 / 互动小说应用。模型走本机 Ollama，会话存在本地数据库，**不联网、不上传数据**。你可以定义角色与世界，用三种方式跟它们对话，让它把发生过的故事记住。

## 主要特点

- **本地离线**：模型、数据、界面资源全在本机，断网照常用；数据不出这台电脑。
- **三种模式**：聊天模式（只说话）、沉浸模式（情境 + 话语）、导演模式（自由写故事）。
- **三层设定**：角色设定、世界设定、我的设定（你是谁）；后面两层都能存成预设，一份预设可以绑给多个角色。
- **长期记忆**：对话变长后自动把早期内容压成摘要，跨会话记得住。
- **附加属性**：给角色定义好感、心情等状态，随剧情变化，点顶栏图标就能看到进度条。
- **电脑端 + 手机端**：Electron 外壳双击即用，手机连同一个 WiFi 就能用同一份数据。

## 界面速览

```
┌────────┬──────────────────────────────────┬────────────┐
│模式 Tab│ [☰] 标题   [🔍][属性][模型][思考]  ⚙ │ 右侧面板   │
│────────│                                  │ ·生成要求  │
│列表区  │        消息流（居中留白）        │ ·世界设定  │
│·角色   │                                  │ ·角色设定  │
│·会话   │                                  │ ·我的设定  │
│────────│  [情境输入框]              [↓]   │ ·记忆      │
│[新建]  │  [话语输入框]            [发送]   │            │
└────────┴──────────────────────────────────┴────────────┘
```

左右两栏都能收起，对话内容始终居中；手机上自动变成单栏（左栏变抽屉、右侧面板从底部弹出）。

## 三种模式

| 模式 | 谁会说话 | 适合什么 |
|---|---|---|
| **聊天模式** | 只有角色说出的话，像发短信，没有动作与旁白 | 轻松日常的对话 |
| **沉浸模式** | 角色的情境（场景、动作、心理）+ 话语，情境你也能写；两个框**至少填一个**就能发出 | 有画面感的互动 |
| **导演模式** | 自由生成的对话与情境，不绑定角色 | 你自己写剧本 |

聊天模式与沉浸模式**共用角色**：同一个角色的性格、说话方式与长期记忆两边一致，在哪边聊过的事另一边都记得。但两边的**会话列表各自独立**——聊天模式里看不到沉浸模式建的会话，反之也一样，切回模式时会回到你上次在看的那条。

导演模式没有角色，故事与记忆按会话单独保存。

## 角色、世界与我的设定

**角色设定**：头像、外观、性格、语言风格、背景故事，随时可改，下一次生成就生效。也可以让模型替你写：填一句话描述想要的设定，不满意点"换一个"重来。生成分两种：

- **开放模式**：五项设定直接展示，随便改。
- **探索模式**：只公开姓名与外观，性格、语言风格、背景故事上锁——它们照常生效、会体现在对话里，但你得聊着慢慢了解。想直接看就点"公开角色设定"，确认后永久解锁。

**世界设定**：给故事定一个世界——名称（只给自己辨认）、描述、规则、词库（专有名词与解释）。用哪份世界由绑定决定：聊天与沉浸模式跟角色走，**导演模式每个会话各带一份**（新建会话时选，默认是"不用世界"）。

**我的设定（你是谁）**：**名字**（只给自己看，面板与列表里靠它辨认）、**称呼**（模型这样称呼你）、身份、外观与头像。称呼、身份、外观会进聊天与沉浸模式的提示词，让角色知道正在跟谁说话；头像会显示在自己消息旁。导演模式不使用它——那里你是写故事的人，不是故事里的角色。

**预设与绑定**：右侧面板里，「我的设定」与「世界设定」两页是**只读**的，显示的内容来自绑定的那条预设：

- 要**改内容**，点「编辑预设」，在弹出的窗口里选一条修改；新建预设在同一个窗口里点「添加预设」（**必须填名字才能保存**），删除也在那里。
- 要**启用或换一份**，点「选择预设」挑一条；已经选过的点「更换预设」。
- 不想用了点「解除绑定」——解除后这项就不写进提示词。
- **新角色默认不启用**这两项，绑定之后才生效。一份预设可以同时给多个角色用，改绑不影响别的角色。
- 右侧面板里改过的内容，面板底部会给「未保存 / 还原」；**两个编辑弹窗（编辑角色、编辑预设）里也有**，手机上不用去找面板底部。

## 记忆与附加属性

**长期记忆**：对话累积到一定长度后，应用在后台自动把较早的消息压成一份结构化摘要，不需要你做任何事，也不打断对话。摘要会在后续生成时交给模型，你可以在右侧「记忆」里查看和手动修改。较早的消息折叠成"已归档 N 条"，点开还能看原文。

**附加属性**：在「角色设定」里给角色定义几条会随剧情变化的属性，比如好感、心情、健康状况。每条要有名称和类型——文字型记一句话（如"有点紧张"），百分比型记 0–100 的数，还能写一句解释告诉模型它是什么意思。定义好之后，模型每轮都会更新这些值，点顶栏那颗图标就能在侧边看到：文字直接显示，百分比显示成进度条。它跟着消息一起保存，想手改就编辑那条消息。

## 常用操作

- **会话内搜索**：点顶栏放大镜，输入即把所有命中处标黄，↑/↓ 键在命中之间跳转，Esc 清空。
- **对话背景**：每个角色最多 10 张背景图，在对话区底部切换；也能一键暂时关闭。
- **消息操作**：复制、编辑、删除、重新生成，生成过程中可随时停止，已经生成的部分保留。
- **自动命名**：新建会话时标题可以留空，角色回复过之后自动总结一个（标题看的是**角色那边**的对话内容）；手动改过名的不会再被覆盖。
- **模型与思考**：顶栏下拉框只列本机已装模型，首次使用需要先选一个；旁边的开关可以关掉思考模式，回复明显更快。
- **手机视图（电脑端）**：标题栏那颗手机图标把窗口收成 375 宽、9:16 的手机比例，用来预览窄屏效果；它只是预览/收纳，退出后回到桌面视图。**启动时两个视图都用默认尺寸**；如果你自己拖过大小，**本次运行内**会记住（切来切去还是你调的那个），下次启动又回到默认。

## 安装与启动（Windows）

**1. 装 Ollama 并拉一个模型**

从 [ollama.com/download](https://ollama.com/download) 安装，然后拉一个小模型先跑通：

```powershell
ollama pull qwen2.5:3b
```

不用特意先把它打开：启动应用时会自动检测并帮你拉起。跑通之后，想要更好的角色扮演效果就在顶栏换成更大的模型（列表里就是你本机 `ollama list` 装过的那些）。

**2. 装 uv，装依赖**

```powershell
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

在项目目录下执行（uv 会按 `.python-version` 自动准备 Python 3.13）：

```powershell
uv sync
```

**3. 启动**

电脑端推荐用桌面外壳，先装一次（约 110MB）：

```powershell
npm install --prefix desktop
```

以后**双击项目根目录的 `start_desktop.bat`** 就能用：它会顺手重建一次前端、起后端、开窗口，关掉窗口即停止。

网页端（也是手机访问用的那条路）：

```powershell
uv run run.py
```

看到 `Uvicorn running on http://127.0.0.1:17800` 后，浏览器打开 `http://127.0.0.1:17800`。

**4. 第一次使用**

1. 在聊天模式或沉浸模式点"新建角色"，填写或用模型生成一个角色。
2. 点"新建会话"，标题可留空，开始对话。
3. 想自己写剧本就切到导演模式，直接新建会话。

## 手机与局域网

手机上用的是同一个界面、同一份数据，电脑只是提供服务：

1. 电脑与手机连**同一个 WiFi**。
2. 打开**推送局域网**开关（**每次启动都是关闭状态**，这是安全默认值）：电脑端点标题栏的 ⚙ 配置 → 打开开关；命令行/网页版启动时加 `--lan`（`uv run run.py --lan`）。
3. 开关打开后，配置面板里才会出现二维码与**访问码**：手机扫二维码即可（没扫成功就在手机上打开 `http://<电脑IP>:17800`，输入配置面板里那 8 位访问码）。进去一次之后这台手机会被记住，不用反复输。

不想让局域网访问就把开关关掉，立即生效（访问码一并作废）。面板里的「重新生成」换一个访问码，先前连上的设备要重新扫。

**安全**：开着时只有带对访问码的设备能读写你的会话；访问码等于钥匙，别发到群里。传输没有加密，同一 WiFi 里抓包仍可能拿到访问码，公共 WiFi 请把开关关掉（同一网络里只有这台电脑自己不受影响）。

## 常见问题

**提示"Ollama 中还没有可用模型"，但我明明有模型**
多半是模型目录不对：Ollama 装在别的盘时，模型放在它旁边的 `models\` 里，而默认的 `%USERPROFILE%\.ollama\models` 是空的。用 `ollama list` 可以确认当前服务看到几个模型；手动起服务时先设好 `OLLAMA_MODELS` 指向真正的目录。

**提示"无法连接 Ollama"**
先等几秒再点提示旁边的重试（它会让后端再确保一次 Ollama）。仍不行就执行 `ollama list` 看命令行是否可用；如果报的是端口被占着却连不上，从托盘退出 Ollama 再重新打开。

**17800 端口被占用，或换了端口后打不开**
端口在 `config.yaml` 的 `server.port`，默认 17800，改完重启即可。换了端口就用新地址访问，旧书签会连不上。

**手机连不上**
依次查：是否同一个 WiFi（公司或学校网络常禁止设备互访）；「推送局域网」开关是否打开；手机上是用的电脑那个局域网 IP（`ipconfig` 里那个），不是回环地址；Windows 防火墙是否放行入站 TCP 17800。放行命令如下，用**管理员** PowerShell 执行一次：

```powershell
netsh advfirewall firewall add rule name="Wonder Realm 局域网访问 17800" dir=in action=allow protocol=TCP localport=17800
```

**手机上一直让输访问码 / 提示访问码不对**
访问码在电脑端 ⚙ 配置 面板里（8 位，字母表里没有 0、O、1、I、L，大小写和连字符随便写）。连错会被拦一分钟再试；点过「重新生成」的话，先前连上的设备要重新扫二维码。

**数据在哪里，怎么备份**
全部数据在 `data/chatbot.db` 这一个文件里（角色、会话、消息、记忆、头像与背景图）。应用**每次启动都会自动备份**一份到 `backups/`，保留最近 14 天；不要在应用运行时手工复制数据库文件。**字数上限**：每个输入框右下角实时显示"已用 / 上限"，到上限就打不进更多字（各字段上限不同，消息与情境为 2000 字）。
